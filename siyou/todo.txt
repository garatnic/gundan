[ ] ボスのステージで通常敵の種類の順番が飛ばされないようにする
    現状：通常敵の種類は (stage - 1) % 3 で決まり、5の倍数はボスに置き換わるため、通常敵の順番が飛ぶ。
    変更案：ボスのステージは通常敵のローテーションに数えない。
    通常敵の種類番号 = (stage - 1 - Math.floor(stage / 5)) % 3
      0 = 単体型、1 = 範囲型、2 = 高速型
      stage % 5 === 0 の場合はボス。
    期待する並び：1単体、2範囲、3高速、4単体、5ボス、6範囲、7高速、8単体、9範囲、10ボス、11高速、12単体。
    変更対象：Index.html の敵種類決定処理。HP・攻撃力・報酬は変更しない。
