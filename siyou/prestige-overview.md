# 算数ぐんだん：プレステージ（転生）再設計の概要・検討経緯
更新日：2026-10-31
状態：構想・要詳細検討。新仕様は未実装、数値は未確定。

## 1. 背景・目的
現行の転生は「当該周回でステージ10をクリアすると解放、いつ転生してもコイン倍率+0.5」という仕組み。ステージ10を超えて進んでも転生報酬が増えず、10クリア即転生の繰り返しが効率的になりやすい懸念がある。
目的は、10での短い周回にも、20・30・50以降を目指す挑戦にも意味を持たせ、転生で長期的な成長・選択肢を作ること。

## 2. 現行実装（Index.html / 20261031-09）
- 転生解放：その周回でステージ10クリア。戦闘停止中のみ実行。
- 転生効果：転生回数+1、コイン獲得倍率=1+0.5×転生回数。
- リセット：ステージ1、所持コイン0、4種の通常強化Lv0と費用初期化、戦場の味方全削除、周回内クリア記録0。
- 維持：転生回数と通算正解数。次の転生には再びステージ10クリアが必要。
- 到達ステージによる報酬差はない。保存未実装のためページ再読み込みでは転生回数も失われる。
- 通常敵HP=ceil(20×1.25^(stage-1))、ボスはさらに1.7倍。通常強化は人数・攻撃力・攻撃周期・HP。

## 3. 新しい基本方針（方向性として合意、詳細未確定）
1. 転生で直接コイン倍率+0.5を得る方式を見直し、専用の「転生通貨」を獲得する方式を検討。
2. 転生通貨を使うショップで永続強化を購入する。未使用通貨・購入済み永続強化は次の周回へ持ち越す構想。
3. ステージ10で転生可能にする条件は維持する方向。転生時は通常コイン・通常強化・ステージをリセットする方向。
4. 転生通貨の獲得量はクリアステージに応じて緩やかな指数関数で増やす。
5. 永続強化は原則、項目ごとに購入するたび次回費用が2倍になる方式を検討。異なる項目の購入回数は互いの費用に影響させない。
6. 敵の「ステージごとのHP成長率」は転生ショップで変えない。敵弱体化は敵HPの倍率等にかける方式を想定。
7. 味方の出撃人数を永続強化で際限なく増やす方針は避ける。人数増加は移動・攻撃判定・描画負荷につながるため。

## 4. 転生ショップの候補
| 項目 | 効果の候補 | 補足 |
| --- | --- | --- |
| 敵HP弱体化 | 購入ごとに敵最大HPを約1%減らす | 0.99倍ずつの乗算案。ゼロ化を防ぐ。計算・丸め・下限は未決定 |
| 敵攻撃間隔弱体化 | 購入ごとに敵攻撃間隔を約1%長くする | 敵の攻撃を遅くする。乗算・上限等は未決定 |
| コイン倍率強化 | 通常コイン獲得倍率を増やす | 上昇量・購入費用は未決定 |
| 味方ユニット解放 | 新しい味方の種類をアンロック | 将来の遠距離型など。性能・価格・解放条件は未決定 |

「敵の基礎HPとステージごとの成長率を上げる」はゲーム全体の初期バランス見直しの候補であり、確定ではない。転生ショップで成長率を下げる案は明確に取り下げた。
現在の味方構成・出撃人数の仕組みは当面維持する方向。敵HPの基礎値を大きくすれば1%弱体化の刻みを扱いやすいが、初回プレイが難しくなりすぎないよう通常強化との再調整が必要。

## 5. 数値イメージ（すべて仮例・未決定）
転生通貨獲得例：P(s)=floor(100×1.08^(s-10))、s>=10。
- ステージ10：100、15：146、20：215、30：466、40：1006、50：2172（概数）。
- 100という基礎報酬と1.08という増加率は例示にすぎない。

ショップ費用例：C(Lv)=100×2^Lv（Lv=購入済み回数、0から）。
- 1～8回目の価格：100、200、400、800、1600、3200、6400、12800。
- 初回費用100は例。各項目で初回価格を変える可能性がある。ユニット解放は一度きりなので別体系を検討。
- HP弱体化は「1回購入で残存HP×0.99」を候補とする。単純加算の-1%を100回積むとHPゼロになり得るため。
- 敵攻撃間隔+1%の定義（加算か乗算か）は未確定。

## 6. 今回の会話での決定・変更の経緯
1. 現行「10クリア以降いつ転生しても+0.5倍」では10を超える動機が乏しいと問題提起。
2. 10で+0.5、以降1ステージごと+0.05を検討。ステージ数あたりの報酬は一定で、後半ほど攻略問題数が増えやすく、10即転生の効率優位を覆しにくいと判断。
3. 11以降+0.1という案も出たが、到達ステージだけで最適値は決められないため確定せず。
4. 専用の転生通貨を受け取り、コイン倍率等をショップで購入する方式へ方向転換。報酬量と強化費用を独立に調整できる点を重視。
5. 味方の基礎値・人数を大きくする案（例：敵HP1000、味方20人）を検討したが、人数の増加は描画・判定負荷が大きい。味方構成は現状維持を志向し、敵の基礎HP・成長率の見直しを議論。
6. 敵の成長率を転生ショップで下げる案は採用しないと明示。代わりに敵HP約1%弱体化、敵攻撃間隔約1%延長、味方ユニットのアンロック、コイン倍率強化を候補にした。
7. 転生通貨は緩い指数関数で増やし、同一ショップ項目は購入のたび費用を2倍にする案に到達。強化を頻繁に買えすぎない設計を狙う。

## 7. 要詳細検討・検証
- 転生通貨の獲得式（基礎点・指数成長率・丸め・ステージ上限）と転生後の残高保持。
- 10・15・20・30・50等での「1問あたり転生通貨」の比較。敵HPは指数成長し、通常強化・永続強化・コイン倍率で進行速度も変化するため、単純なステージ数比較だけで判断しない。
- ショップ各項目の初期価格・倍増ルール・上限、HPデバフの計算・下限、攻撃間隔デバフの計算・上限、コイン倍率の効果量。
- 味方アンロックの種類・効果・購入条件。将来の遠距離味方を含めた戦闘仕様との整合。
- 敵の基礎HP・成長率のゲーム全体の調整（ショップで成長率は変えない）、初回プレイの難易度、通常強化の価値。
- 転生ショップUI、購入タイミング、転生確認、通貨・永続強化の保存方法。現行のセーブなし仕様をどう改めるか。
- 既存の転生回数・倍率との移行、ゲーム本体仕様書・バランス資料の更新と試遊検証。
