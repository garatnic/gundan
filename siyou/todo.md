  現状：通常敵の種類は (stage - 1) % 3 で決まり、5の倍数はボスに置き換わるため、通常敵の順番が飛ぶ。
  変更案：ボスのステージは通常敵のローテーションに数えない。
  通常敵の種類番号 = (stage - 1 - Math.floor(stage / 5)) % 3
  0 = 単体型、1 = 範囲型、2 = 高速型

  期待する並び：1単体、2範囲、3高速、4単体、5ボス、6範囲、7高速、8単体、9範囲、10ボス、11高速、12単体。

- [ ] ボスの攻撃行動を5パターン用意する
  経緯：現在のボスは半径20pxの赤い円1個を予告表示し、戦闘時間1秒後に円内の味方へダメージを与える。移動中の味方を狙うと予告後に移動して空振りしやすく、通常範囲型より弱く見えるという問題がある。
  検討する5パターン：
  1. 大きめの円1個：味方の集団を狙う広範囲攻撃（半径60pxは仮案）。
  2. 小さい円を複数：複数地点を同時に狙う（半径20px×4個は仮案）。
  3. 扇形：ボスから特定方向に広がる攻撃。描画は扇形または三角形による代用も検討。
  4. 放射線型：ボスから複数方向に伸びる細い棒状の攻撃。
  5. 自分中心の全周円形：ボス自身と周囲に張り付いた近接味方の全体が入る固定半径。将来の遠距離味方まで巻き込むために半径を自動拡大しない。
  共通の検討事項：赤い予告を1秒表示してから範囲内の味方にダメージ。表示形状と命中判定を一致させ、複数範囲が重なっても1回の攻撃で同じ味方へのダメージは1回とする。移動中の味方への空振り対策として、接敵して停止中の味方を優先して狙う案がある。
  重要な未決定事項：ボスの種類を5種類に増やすか、1体のボスが戦闘中に5種類の攻撃を使い分けるかは実装時に検討する。各パターンの寸法・個数・確率・攻撃周期・選択方法も未確定。
  状態：設計案のみ、未実装。
