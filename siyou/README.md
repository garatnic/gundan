## 記録の読み方
「ユーザー要望」はゲームの方向性。「実装済み」は現行モックの事実。
提案をモックに入れたことは、最終仕様としての承認を意味しない。
ユーザーの試遊感想は「今のところいい感じ」。個別数値の最終承認ではない。
