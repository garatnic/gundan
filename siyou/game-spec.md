# ゲーム仕様
更新日：2026-11-01

## 1. ユーザー要望
- 画面中央に敵、画面下から小さい味方が多数出撃する。
- 算数を解くとゲームが進む。解かなければ進めない。
- 最初は貧弱で、育成による成長と達成感を感じられる。
- 正解で初期3体が出撃する。
- 味方はHP、攻撃力、攻撃周期を持つ。
- 敵はHP、攻撃力、攻撃周期、攻撃範囲を持つ。
- 倒された味方がコインになり、アップグレードに使える。
- 強化項目は人数、攻撃力、攻撃周期、HP。
- プレステージでコイン倍率を得る。

## 2. 現行ゲーム進行（v12／20261101-09、工程A～E＋前線配置実装済み）
1. 初期は戦闘停止。戦闘中でも算数4択へ解答できる。
2. 正解すると即座に3＋人数Lv体を出撃させ、残り時間を3.0秒に戻す。すぐ次問を表示。
3. 不正解では同じ問題を再挑戦。誤答ボタンだけ無効化し、出撃・時間回復はない。戦闘中は時間が減る。
4. 残り0秒で戦闘だけ自動停止。問題・選択肢は保持し、次の正解で再開。
5. 全敵撃破で報酬を一度だけ加算し次ステージへ。生存兵のHP・位置・攻撃待ち時間と残り戦闘時間を維持。生存兵換金なし。
6. 死亡した味方は1体につき1×コイン倍率。全滅でも敵HP・ステージを維持して再出撃可能。
7. 強化購入成功で作戦停止。移動・攻撃・予告時間・残り時間を停止。問題と同じ領域に「戦闘再開」を表示し、元の問題・誤答状態を保持。停止中の追加購入可。
8. 再開時に残り時間を維持。0秒なら次の正解まで自動停止。
9. 転生は10クリア後、戦闘停止中（自動停止／作戦停止）のみ。実行時に問題UI・予告・戦闘状態も初期化。解放条件・倍率・リセット対象は従来どおり。

購入失敗時に停止するかは未決定。現在は購入成功時のみ停止する暫定仕様。

## 3. 算数（実装済みの仮設定）
問題と4択ボタンを横一列に表示する。式内の空白と左右余白を縮め、4つのボタンを均等配置する。入力欄・出撃ボタンは廃止し、正解ボタンを押すと即出撃。
選択肢は正解と、正解との差が−9〜＋9の非負整数から選んだ誤答3つ。重複なし、順番は毎問ランダム。
不正解はそのボタンを無効化し、同じ問題で再挑戦。作戦停止中を除き、戦闘中も4択を操作できる。
4種類を各25%でランダムに選ぶ。難易度選択は未実装。

| 演算 | 出題範囲 |
| --- | --- |
| 足し算 | 1〜20 ＋ 1〜20 |
| 引き算 | a=1〜20、b=0〜a。答えは0以上 |
| 掛け算 | 1〜9 × 1〜9 |
| 割り算 | 除数1〜9、商1〜9から被除数を生成。余りなし |

正解速度で即時出撃の頻度が変わる。正解自体の追加コイン報酬や誤答による資金減少はない。

## 4. 戦闘の詳細（現行実装）
- 味方は敵下側の接触弧と、その後方のハニカム状（三角格子）の空き位置を予約して移動。予約は維持し、前線の死亡時は近い待機兵を優先して補充する。詳細は[前線配置](frontline-overview.md)。
- 味方の初撃は表面間距離が兵種別射程＋許容誤差以内になった更新で即時。現在の基本兵射程0px・許容誤差0.75px。以後はmax(0.75, 5×0.9^Lv)秒。射程外ではcdを保持し、射程内のみ減らす。攻撃時は周期へ戻して連続攻撃の蓄積を防ぐ。
- 敵の初撃は接敵した味方が現れた更新で即時。以後は敵の攻撃周期に従う。
- 敵の攻撃タイマーは接敵中の味方がいるときだけ進む。
- 単体攻撃の対象は接敵済みの味方のうち現在HPが最少の1体。
- 通常の範囲型は、その対象を中心として半径55px内の接敵済み味方に命中。
- ボスの範囲攻撃は別処理。生存味方からランダムに1体を選び、その中心から半径16px以内に円の中心をランダム配置。半径20pxの赤い円を1個表示し、出現時に最低1体の生存味方の中心が必ず円内に入る。円は位置固定。生存味方なしなら設置しない。
- 赤い円を予告表示し、戦闘時間で1秒経過してから、その時点で円内に中心座標がある味方へ攻撃力分のダメージ。移動中も判定対象。問題待ち中は予告タイマーも停止して円を保持する。判定後に円を消す。継続ダメージなし。敵撃破・転生では未発動の予告を破棄する。
- bossAreaAttackのradius、count、delay（初期1秒）で調整可能。将来の半径100px×1、半径20px×4は候補。複数円では同じ攻撃内で重なっても1体につき1回ダメージ。
- 現在のボスは接敵した味方がいる時に攻撃タイマーが進む。
- 通常敵は接触中の味方だけを攻撃対象にする（配列位置・予約列・行動ラベルでは判定しない）。ボスの赤い円は従来どおり移動中の味方も対象。
- 味方の攻撃処理が先。その処理で敵を倒せば、その更新の敵反撃は行わない。
- 味方同士の移動経路の衝突を最小中心間隔11pxで防ぐ。物理的な押し合いと新兵種は未実装。
- 人数の購入は次回出撃数に反映。既存味方の数は増えない。
- 攻撃力・攻撃周期は既存味方にも反映。ただし既に進行中の攻撃待ち時間を再計算はしない。
- 味方の初期HPは1。HP購入は既存味方の現在HP・最大HPを各1増やす。新規出撃のHPは1＋HPレベル。

## 5. 表示
- 敵：ステージ、種類、HPバー、攻撃力、周期、単体／範囲
- 味方：小さい盾の絵文字、個別HPバー
- 戦闘状態：停止／残り秒数、生存人数
- 資金、正解数、コイン倍率
- 強化：現在レベル、現在値→強化後の値、費用
- ダメージ・コインの浮き文字、範囲攻撃の円
- 画面幅に合わせた表示、明暗テーマへの対応

コインは演出と同時に即時加算される。コインが手元まで飛ぶ演出は未実装。

## 6. 保存と制限
- セーブ機能なし。再読み込みで資金・強化・ステージ・転生・正解数が初期化。
- 転生は確認ダイアログなしで実行。
- 絵文字の見た目は環境に依存。
- 戦場は100dvh（未対応環境100vh、最小265px）。表示窓265pxから縦スクロール。敵y=116、新兵は下端22px付近の空き位置から出撃。下端が埋まれば上の千鳥列へ拡張し、既存兵に重ねない。初期スクロール0で敵表示、その後の自動スクロールなし。
- 判定・HPバー・予告・エフェクトは戦場内のワールド座標。スクロールは表示にのみ作用し、画面外でも戦闘継続。歩兵速度175px/秒。攻撃範囲はワールドpx単位。
- 現行モックの戦闘時間は描画フレームの経過を上限0.04秒として積算。非表示時に実時間分を一括進行する設計ではない。


## 小数HP・共通処理（工程B）
- 内部HP・攻撃力・ダメージを小数のまま計算。既存の敵生成時のceil式はバランス維持のため変更しない。
- HP減算時の誤差閾値はNumber.EPSILON×max(|減算前HP|, |ダメージ|)×8。閾値以下の残差を0へ。正の小数HPを一律の固定閾値で消さない。
- HP数値表示は小数2桁まで、正の0.01未満は「<0.01」。HPバーは内部値の比率を0～100%に制限。表示丸めを内部値へ戻さない。
- 味方の標的ID確認・移動・射程・攻撃→既存ボス予告解決→死亡整理→生存敵攻撃→死亡整理→全敵撃破判定。撃破した敵は反撃せず、旧敵の予告とエフェクトは遷移時に破棄。
- ボス予告は生成した更新では時間を減らさず、満1秒の戦闘時間後に解決。新しい予告も自動停止・作戦停止中は保持。
- 非表示中は戦闘を進めず、復帰時の実時間を一括加算しない。
