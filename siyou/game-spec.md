# ゲーム仕様
更新日：2026-10-31

## 1. ユーザー要望
- 画面中央に敵、画面下から小さい味方が多数出撃する。
- 算数を解くとゲームが進む。解かなければ進めない。
- 最初は貧弱で、育成による成長と達成感を感じられる。
- 正解で初期3体が出撃する。
- 味方はHP、攻撃力、攻撃周期を持つ。
- 敵はHP、攻撃力、攻撃周期、攻撃範囲を持つ。
- 倒された味方がコインになり、アップグレードに使える。
- 強化項目は人数、攻撃力、攻撃周期、HP。
- プレステージでコイン倍率を得る。

## 2. 現行モックのゲーム進行（実装済み）
1. 算数を1問表示。戦闘は停止している。
2. 不正解の場合は同じ問題を再挑戦。出撃・戦闘時間の進行・資金減少なし。
3. 正解すると味方が出撃し、戦闘が最大3秒進む。
4. 味方は敵の手前に移動して停止し、繰り返し攻撃。敵も反撃する。
5. 3秒終了で戦闘停止、新しい問題へ。敵HP、味方HP・位置、攻撃待ち時間は持ち越す。
6. 味方が倒されると1体分のコインを自動回収。
7. 敵撃破で生存味方を精算して全員帰還、撃破報酬を加算。
8. 次ステージの敵に切り替わり停止。次の正解で再開。

敵を早く倒した場合は、その時点で3秒枠を終了する。余った時間を次の敵へ持ち越さない。
戦闘中は解答・強化・転生を操作できない。
全滅によるゲームオーバーはなく、次の正解で新しい味方を出せる。

## 3. 算数（実装済みの仮設定）
問題と4択ボタンを横一列に表示する。式内の空白と左右余白を縮め、4つのボタンを均等配置する。入力欄・出撃ボタンは廃止し、正解ボタンを押すと即出撃。
選択肢は正解と、正解との差が−9〜＋9の非負整数から選んだ誤答3つ。重複なし、順番は毎問ランダム。
不正解はそのボタンを無効化し、同じ問題で再挑戦。戦闘中は4択すべて無効、次問で復帰。
4種類を各25%でランダムに選ぶ。難易度選択は未実装。

| 演算 | 出題範囲 |
| --- | --- |
| 足し算 | 1〜20 ＋ 1〜20 |
| 引き算 | a=1〜20、b=0〜a。答えは0以上 |
| 掛け算 | 1〜9 × 1〜9 |
| 割り算 | 除数1〜9、商1〜9から被除数を生成。余りなし |

正解速度による報酬差や不正解ペナルティはない。

## 4. 戦闘の詳細（現行実装）
- 味方は各自のランダムな接敵位置へ移動。敵の下側の弧に並ぶ。
- 味方の初撃は接敵後の更新で即時。以後は味方の攻撃周期に従う。
- 敵の初撃は接敵した味方が現れた更新で即時。以後は敵の攻撃周期に従う。
- 敵の攻撃タイマーは接敵中の味方がいるときだけ進む。
- 単体攻撃の対象は接敵済みの味方のうち現在HPが最少の1体。
- 範囲攻撃は、その対象を中心として半径55px内の接敵済み味方に命中。
- 移動中の味方は敵の攻撃対象にならない。
- 味方の攻撃処理が先。その処理で敵を倒せば、その更新の敵反撃は行わない。
- 味方同士の衝突や押し合い、兵種の違いは未実装。
- 人数の購入は次回出撃数に反映。既存味方の数は増えない。
- 攻撃力・攻撃周期は既存味方にも反映。ただし既に進行中の攻撃待ち時間を再計算はしない。
- 味方の初期HPは1。HP購入は既存味方の現在HP・最大HPを各1増やす。新規出撃のHPは1＋HPレベル。

## 5. 表示
- 敵：ステージ、種類、HPバー、攻撃力、周期、単体／範囲
- 味方：小さい盾の絵文字、個別HPバー
- 戦闘状態：停止／残り秒数、生存人数
- 資金、正解数、コイン倍率
- 強化：現在レベル、現在値→強化後の値、費用
- ダメージ・コインの浮き文字、範囲攻撃の円
- 画面幅に合わせた表示、明暗テーマへの対応

コインは演出と同時に即時加算される。コインが手元まで飛ぶ演出は未実装。

## 6. 保存と制限
- セーブ機能なし。再読み込みで資金・強化・ステージ・転生・正解数が初期化。
- 転生は確認ダイアログなしで実行。
- 絵文字の見た目は環境に依存。
- 攻撃範囲は画面上のpx単位。狭い画面では相対的に範囲が広くなる。
- 現行モックの戦闘時間は描画フレームの経過を上限0.04秒として積算。非表示時に実時間分を一括進行する設計ではない。
