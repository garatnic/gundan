# 味方の重なり防止・前線配置
更新日：2026-11-01

状態：実装・自動検証済み／ユーザー実機検証待ち

## 配置と射程の分離
基本兵を円（半径11px）、敵を円（半径26.5px）として扱う。味方表示幅22pxと敵の53px正方形表示枠に対応する。敵の描画枠は縦横・行高を明示し、中心座標と幾何学判定を揃える。絵文字自体の透明部分には端末差がある。

`surfaceDistance = hypot(味方x−敵x, 味方y−敵y) − 味方radius − 敵radius`

`canAttack = 生存中 && surfaceDistance <= attackRange + contactTolerance`

基本兵はunitTypes.basicのradius=11、attackRange=0、speed=175を出撃時に参照。ユニットごとにattackRangeを持ち、許容誤差は0.75px。配置キーや前列／後列番号、攻撃人数で攻撃可否を決めない。射程を22pxへ変えるテストでは、斜めにずれた最初の待機列が届き、真後ろの次の位置は届かないことを距離だけで確認する。遠隔攻撃や回復の実装は今回含まない。

## 空き位置と予約
- 敵ごとの接触弧（下半円）と後方の三角格子を生成する。接触弧の半径は敵radius＋基本兵radius。弧の収容数は円周と間隔から算出するため固定人数ではない。少人数は弧の中央付近を先に使う。
- 後方は中心間隔20px、縦ピッチ20×√3/2px、隣の列を半間隔ずらすハニカム状の配置。前方の空き列から近い兵士を割り当てる。移動順と予約順が逆転して前方の味方を塞がないよう、配列順だけで割り当てない。
- 通常格子が収容不足になった時だけ11px間隔の格子に圧縮する。通常から積極的に重ねない。
- 各味方はtargetId、placementKey、state（moving/waiting/attacking）、radius、attackRange、cdを保持。既存予約は原則維持し、出撃・死亡・敵変更・寸法変更時にだけ予約を更新する。
- 接触位置に空きができたら、既に別の接触位置を予約していない兵士から、その空き位置に最も近い生存兵を選ぶ。同距離はIDで安定化。1位置につき1予約。補充で現在位置を瞬間移動しない。
- 敵位置・半径・戦場寸法が変われば目標位置を再生成できる。敵IDごとに格子を保持するが、複数敵の出現・敵の移動自体は追加しない。

## 出撃と移動
- 新兵は下端22px付近の空き位置を中央から左右へ探し、埋まっていれば上の千鳥列へ探す。正解時の即時出撃数は変更しない。
- 通常の移動は175px/秒以内。空間ハッシュで近くの味方のみ調べ、移動経路を円の掃引として判定し、中心間隔11px未満への入り込み・敵内部への入り込みを抑える。
- 弧の左右端へ向かう兵士は20px外側の接近点を経由し、隣接する前線兵に遮られて補充不能になることを防ぐ。
- 障害物があれば進行角を少し変えて回避する。前フレームの回避方向に小さい優先度をつけ、頻繁な左右切替を抑える。押し出しの瞬間移動は行わない。
- 全判定はワールド座標。scrollTopを参照せず、画面外でも行動する。

## 戦闘との接続
- 射程内だけ攻撃cdを減らし、射程外ではcdを維持。攻撃したら現在のperiodへ戻す。離脱中に負のcdを蓄積して接敵時に多段攻撃することはない。
- 基本兵周期max(0.75,5×0.9^速度Lv)秒、敵周期10／15／5秒、ボス予告1秒を維持。
- 通常敵の接敵候補も接触距離から選ぶ。単体HP最少、通常範囲半径55px、ボスの予告と命中座標は従来どおり。
- 0秒停止・作戦停止中はフレームから戦闘更新を呼ばず、配置予約・移動・攻撃・予告も止める。新兵の生成は算数正解イベントでのみ行う。
- 死亡時の1コインは一度だけ。ステージ遷移は予約と対象IDを再構築し、生存HP・座標・cdを維持。転生は兵と予約を全消去し、従来の倍率・解放・リセット範囲を維持。
- 保存機能は現行にも存在しない。今回も新規実装しない。

## 検証と限界
`node tests/battle.cjs` と `node tests/formation.cjs`。後者は少人数、90体密集、接触／非接触、死亡補充・最寄り優先、予約一意性、離脱cd、射程変更、両停止、ステージ遷移、敵座標変更時の目標更新、スクロール独立、300体性能、240×265pxでの圧縮を検証する。JavaScript構文チェックも別途実施する。

有限の画面を11px間隔でも埋め尽くす兵数には、物理的に全員を置けない。現時点では出撃上限・待ちキューを導入せず、この極端な場合は出撃座標の重なりが残り得る。通常検証の300体と狭小画面120体では重複予約なし・中心距離11px以上を確認する。上限なしの無限収容を保証するものではない。端末実負荷・長時間・見た目はユーザー実機確認後に都度調整する。
